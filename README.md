# 🏫 School Bot

Telegram-бот для школьных услуг: расписание, звонки, объявления и многое другое.

## 🚧 Статус

Проект в разработке.

## 📋 Планируемые функции

- [ ] Расписание уроков по классам
- [ ] Расписание звонков
- [ ] Объявления
- [ ] Замены уроков с уведомлениями
- [ ] Меню столовой

## 🛠 Стек

- Python 3.11+
- aiogram 3

## 🚀 Запуск

1. Скопируйте `.env.example` в `.env` и укажите токен бота от [@BotFather](https://t.me/BotFather).
2. Установите зависимости и запустите бота (инструкции появятся позже).
