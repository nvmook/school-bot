# 🏫 School Bot

Telegram-бот для школьных услуг: расписание, звонки, объявления и многое другое.

## 🚧 Статус

Проект в разработке.

## 📋 Планируемые функции

- [ ] Расписание уроков по классам
- [ ] Расписание звонков
- [ ] Объявления
- [ ] Замены уроков с уведомлениями
- [ ] Меню столовой

## 🛠 Стек

- **Хостинг:** [Vercel](https://vercel.com) (serverless-функции, бот работает через webhook)
- **База данных:** [Turso](https://turso.tech) (libSQL / SQLite)
- Остальное — в процессе выбора
